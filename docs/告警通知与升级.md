<a id="usage"></a>
## 使用方式

在“运行监控”查看告警路由、当前静默、最近100条投递任务及最近200次尝试。节点、认证拒绝率、密钥插件、证书和已入库的数据库状态转换均可产生通知。

邮件、短信、Webhook使用相同的HTTPS/mTLS插件协议。KeyGate保存固定收件组标识，插件将其映射到经过核验的邮件地址、手机号或Webhook目标；管理页面不接受任意URL或联系方式。

本机模拟插件只确认接收，不向外部发送真实消息。真实厂商尚需提供适配服务及验收，不能把页面“插件确认接收”当作短信送达或邮件已读。

<a id="configuration"></a>
## 配置路由

私有JSON文件权限0600，首次配置通过 `-alert-notify-plugin-file` 指定。已初始化的持久部署通过候选Settings中的 `alertNotifyFile` 和受控升级安装；普通启动拒绝未批准的文件或证书更改。多节点必须使用同一发布配置。

```json
{
  "routes": [
    {
      "id": "email-oncall",
      "channel": "email",
      "target": "operations-oncall",
      "level": 0,
      "escalationSeconds": 0,
      "plugin": {
        "url": "https://alert-adapter.example/alerts",
        "allowedIPs": ["192.0.2.10"],
        "caFile": "/secure/alerts/ca.pem",
        "certificateFile": "/secure/alerts/client.pem",
        "keyFile": "/secure/alerts/client.key"
      }
    },
    {
      "id": "sms-escalation",
      "channel": "sms",
      "target": "duty-leader",
      "level": 1,
      "escalationSeconds": 900,
      "plugin": {
        "url": "https://alert-adapter.example/alerts",
        "allowedIPs": ["192.0.2.10"],
        "caFile": "/secure/alerts/ca.pem",
        "certificateFile": "/secure/alerts/client.pem",
        "keyFile": "/secure/alerts/client.key"
      }
    }
  ]
}
```

| 字段 | 决定的行为 |
| --- | --- |
| id | 本域唯一固定路由，不能重复；最多12条 |
| channel | email、sms、webhook，插件按通道分流 |
| target | 1至128字符合法标识符，引用插件维护的收件组 |
| level=0 | 接收首次触发与恢复；启用配置至少有一条此类路由 |
| level=1 | 持续未恢复达到escalationSeconds后升级；范围60至86400秒 |
| allowedIPs | 固定1至4个IP，仍校验证书主机名；禁止代理、重定向和DNS重新选目标 |
| caFile等 | 证书、私钥及配置文件进入受保护依赖快照 |

Webhook也使用上述结构，将channel设置为webhook，target引用目标组。可以配置多个升级路由及不同延时；每个事故每个路由只生成一次升级，不做无限循环提醒。路由删除或内容改变后旧未完成任务失效，不补发配置启用前的历史触发。

<a id="delivery"></a>
## 投递与升级规则

```text
monitor event -> shared incident -> primary queue -> mTLS adapter
                       |
                       +-> still active after delay -> escalation queue
                       |
                       +-> recovery -> close old work -> recovery queue
```

共享域锁和唯一约束去重，多节点领取30秒租约后释放事务，再进行外部调用。消息ID稳定，重试不改变正文，不将尝试次数或队列状态发给插件。

每条消息最多5次尝试，失败后按 `30 * attempt * attempt` 秒延迟，即30、120、270、480秒后重试。仅HTTP200、204确认接收；202、重定向、断连、超时均按未确认处理。每次结果与过期租约均保留记录。最后一次发送者崩溃后也会收敛为失败，不能永久停在发送中。

持续故障即使首次发送失败，仍按事故开始时间升级。恢复关闭旧事故，旧pending/sending/failed触发任务失效；已发出的消息不能撤回。恢复通知发给初次组，以及已经生成升级任务的组。若新故障再次发生，使用新的事故和消息ID。

插件必须持久化幂等记录：同一Idempotency-Key与相同正文重复请求应返回相同接收结果；同ID不同正文应拒绝。无法承诺跨网络恰好一次，第三方实际送达查询与回执尚未实现。

<a id="silence"></a>
## 静默操作

全域策略管理员完成近期本人验证后，在“设置静默”选择已登记的告警代码、原因及期限。支持15分钟、1小时、4小时、24小时；API最长86400秒。解除必须填写原因，审计员只能读取。

静默按告警代码作用于本域所有节点、所有通道、触发、升级及恢复通知，不修改原始告警状态。静默期间仅推迟队列，不消耗尝试；解除或到期后处理仍有效的通知。故障在静默期间恢复时，旧触发与升级失效，恢复通知仍按队列发送。在途请求不能撤回。此操作记录操作者、原因和审计事件，不额外启动多人审批流程。

<a id="api"></a>
## 接口与投递契约

- `GET /api/alert-deliveries`：全域策略管理员/审计员完成本人验证后查看路由、静默、任务、尝试；最近100/200条，历史分页与归档待扩展。
- `POST /api/alert-silences`：近期本人验证的全域策略管理员，必须有现有会话的CSRF头。请求 `{"code":"auth_failure_rate","reason":"维护窗口","seconds":900}`；0秒解除。204成功；400输入无效、403权限或验证不足。仅接受已登记监控代码。

插件收到POST与 `Idempotency-Key: <id>`，正文固定为：

```json
{
  "id": "stable-delivery-id",
  "incidentId": "incident-id",
  "eventId": "monitor-event-id",
  "routeId": "email-oncall",
  "channel": "email",
  "target": "operations-oncall",
  "kind": "trigger",
  "code": "auth_failure_rate",
  "nodeId": "",
  "observedAt": "2026-10-21T12:00:00Z",
  "path": "/manage#monitoring"
}
```

kind为trigger、escalation、recovery。nodeId为空表示集群汇总；observedAt为事故或转换入库时间，不保证等于原始故障发生时间。通知只供定位，接收人登录管理页核对现状，正文不含执行凭证。

开发模拟：`KEYGATE_ENV=development go run ./cmd/mock-alert -port 19454 -output data/mock-alert -fail-first 1`。私有connection.json提供插件配置，fail-first只在模拟器中对每个ID前N次返回失败，便于验证重试；内存去重仅适用于测试。

<a id="limits"></a>
## 故障边界与升级

本功能依赖权威数据库队列。数据库彻底不可用时，无法可靠领取和保存外部通知，仍需独立日志采集与 `/health/ready` 告警；恢复且节点许可有效后才补存转换。进程丢失的数据库转换不能凭空补造，外部监控不可省略。

schema25增加告警路由、事故、消费水位、静默、任务和尝试表，纳入签名检查点。支持21/22/23/24到25受控升级；停服捕获最新检查点、执行upgrade、再run，不使用init恢复旧域。隔离恢复作废旧任务、结束旧事故、清除旧静默并推进历史消费水位，避免重放备份通知；重新采集后持续故障产生新的转换。

【涉及其他业务】持久配置增加告警插件及证书依赖，检查点与隔离恢复增加告警表处理，管理页对话框增加所有权清理。审批通知与证书提醒传输行为保持原契约；本批需回归旧通知、原管理登录、升级、隔离和快照。生产厂商、真实送达、独立外部监控与生产演练仍待验收。
