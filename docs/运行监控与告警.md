# 运行监控与告警

管理页左侧“运行监控”查看节点、认证结果、密钥插件、证书和告警转换记录。仅完成本人验证的全域策略管理员、全域审计员可读，局部授权不能查看。无新增监控写接口。

## 采集与判定

后台每15秒采集一次，通过共享 PostgreSQL 汇总同一管理域的各应用节点。节点使用现有租约判断在线、过期、隔离及已排空；采样同时绑定节点 ID、generation、incarnation，旧实例采样不能证明新实例正常。在线节点45秒没有对应采样触发缺失告警。

| 项目 | 规则 |
| --- | --- |
| 认证拒绝率 | 当前分钟及前4个分钟桶，按入口分别汇总；成功加拒绝至少20次、拒绝率至少20%告警 |
| 系统错误 | 认证入口返回5xx单独统计；窗口内存在即告警，不计入拒绝率分母 |
| 密钥插件 | 已启用内部软件及通用远程插件健康探测；真实失败告警，整批预算不足显示未知并单独提醒 |
| 证书 | 当前应用根、状态签名证书、启用服务的当前证书；7天、24小时、1小时、已过期分级；无法解析或尚未生效另报异常 |
| 数据库 | 独立 Ping 限时2秒，首次失败及状态变化输出中文结构化日志；现有就绪检查同时反映异常 |

插件最多16个并发、单次1秒、整批8秒。硬件预留接口显示“接口预留”，不声称可用。邮件、短信、硬件验证器的健康探测尚未统一，本页只覆盖密钥提供器。

## 统计范围与历史

统计 HMAC 认证探测、H5 认证提交、账号密码第一步、OIDC 回调的 HTTP 结果。密码第一步成功不等于完整 MFA 登录成功。入口之前的 TLS、公共限流、路径拒绝等不计入；不替代入口访问日志。4xx记拒绝、5xx记系统错误，没有样本显示“无样本”。

请求路径只更新有界内存计数，不新增数据库监控写入。每个进程保存累计分钟快照，重试覆盖不重复累加；突然终止可能丢失最后一次采集后的计数。窗口内已退出进程的历史认证结果仍参与汇总。样本一天后清理，告警转换记录保留，页面最近100条；历史归档、分页、保留期限管理待扩展。

共享域事务去重触发与恢复，提交成功后才打印告警日志；数量变化但未跨越告警状态不重复发事件。读取节点及进程各最多256项、证书1000项，达到上限明确提示采集不完整，不能据此判定全部正常。页面手动刷新，不承诺秒级自动推送。

## 数据库故障边界

数据库不可用时管理接口也可能返回503，不能依赖页面或写库来报告数据库故障。应由独立监控系统采集应用日志及现有 `/health/ready`；本次未接外部短信、邮件、Prometheus 或告警平台。

本进程最多暂存64条数据库状态转换，溢出计数在页面展示。数据库恢复且实例仍通过租约隔离校验后补存，重复提交不重复写；进程重启会丢失未提交事件。长时间故障导致节点租约过期时不会自动复活，也不保证补存成功，按原有受控重启/节点加入流程处理，以外部日志为依据。

## 升级与影响

新增 schema24 三张监控表，支持21/22/23到24受控升级。先停应用、获取新签名检查点，再执行 upgrade，最后 run；普通启动不执行DDL。保留原管理域、配置和密钥材料，不能用 init 替代升级。新表纳入检查点，旧schema捕获与核验跳过尚不存在的新表。

【涉及其他业务】认证入口增加结果计数，节点/管理域增加只读汇总，持久部署升级及检查点增加监控表。未更改公共鉴权、TLS、CSRF和租约规则；相关认证、隔离、升级、检查点及浏览器回归须随本批验收。开发软件模式的通过不代表生产安全验收完成。
