# 运行模式与生产阻断

| 配置 | 可选值 | 默认值 |
| --- | --- | --- |
| KEYGATE_ENV | development、test、production | development |
| KEYGATE_ROOT_MODE | disabled、development_software、kms、hsm | disabled |

- `disabled` 表示不启用根密钥能力，不提供认证或密钥处理；当前服务仍只有本机存活检查。
- `development_software` 仅允许开发和测试环境。当前仅允许选择模式，软件根密钥加载及业务调用尚未接入，不会自动产生默认根密钥。
- production 配置 disabled 或 development_software 时，启动前拒绝运行。
- kms 和 hsm 尚未实现，任何环境选择它们均拒绝启动，不以插件名字代替实际能力验证。
- 未知环境或模式均拒绝启动。生产模式目前因此不能启动，待 KMS/HSM 实现及验收后再解除对应阻断。

示例：`KEYGATE_ENV=production KEYGATE_ROOT_MODE=development_software go run ./cmd/keygate` 必须以失败状态结束。

配置由部署方控制，不构成抵御服务器管理员恶意修改代码或伪装环境的独立安全边界。后续生产准入还要在发布平台校验环境、镜像及 Provider 能力，不能只靠环境变量证明合规。
