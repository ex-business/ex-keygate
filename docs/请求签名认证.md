# 开发后端请求签名认证

本批接通 `DevelopmentKeys.AuthenticateProbe`，仅验证直接发给 ExKeyGate 的实际 HTTPS 请求。管理与交付 HTTP 入口在后续小点挂载；本接口不向业务网关颁发可转移授权，未接 KMS/HSM 或生产服务。

## 固定 Profile

采用 [RFC 9421](https://www.rfc-editor.org/rfc/rfc9421.html) HMAC-SHA256 与 [RFC 9530](https://www.rfc-editor.org/rfc/rfc9530.html) SHA-256 Content-Digest。实现严格子集，不是通用 Structured Fields/RFC 9421 解析器：只接受单一标签 `keygate`、固定组件顺序、固定参数顺序和规范编码，未知参数、重复签名及其他等价但未支持的序列化形式均拒绝。

覆盖顺序：`@method @scheme @authority @path @query content-digest content-type x-keygate-client x-keygate-key-version x-keygate-audience x-keygate-environment x-keygate-request-id`。每个请求均要求 `Content-Type: application/json`，空正文同样提供摘要。算法固定 `hmac-sha256`，用途固定 `ex-keygate-auth-v1`，keyid 为 `clientId/version`。

Signature-Input 参数顺序为 `created;expires;nonce;keyid;alg;tag`；时间为无前导零整数秒，签名窗口不超过 60 秒。nonce 是 32 字节的新随机数，使用无填充 base64url。Signature 和 Content-Digest 使用有填充标准 base64。`@authority` 小写并去除 HTTPS 默认 443 端口；路径和查询保留实际编码及顺序，`@query` 含前导问号。拒绝 Trailer、Content-Encoding 和重复必需头；正文最大 1 MiB。

完整且可复现的消息、公开测试材料、头部及签名基串见 `internal/httpsign/testdata/vector.json`。运行 `python3 scripts/signature-vector.py` 可独立复核 Python 与 Go 结果；其中材料只用于公开固定测试，不得用作实际密钥。

## 权威事务

数据库检查客户端启用、后端 HMAC Profile、Provider 固定内部软件、专用根及材料指纹、active/retiring 状态和有效期。pending/staged/disabled/expired 密钥均拒绝。校验实际收到的正文摘要后再验签，不能只验证摘要头。

数据库时间要求 created 不超过当前时间 30 秒，且当前时间严格小于 expires。验签通过后在同一事务消费带环境/客户端/版本作用域的 nonce，保存至完整签名失效时间。失败不消费成功资格；重复 nonce、数据库故障、事务提交错误都拒绝。

认证与停用使用同一安全域锁。停用提交后新开始的认证立即拒绝；先完成的认证不追溯取消。软件解密不消耗包裹预算，不缓存权限、明文密钥或启用状态。当前同域串行模型优先保证正确性，尚未通过吞吐、多中心或灾备验收。

## 验证

临时 PostgreSQL 全量 race 覆盖签发/持有证明前拒绝、激活后成功、跨实例同签名并发只成功一次、正文替换、错误受众、超时/未来时间、Profile/根/客户端停用、密钥过期、数据库不可用及普通 HTTP 拒绝。另有字段篡改、重复头、编码与用途标签以及 Python 固定向量测试。

【其他业务影响待确认】本批没有修改现有业务网关、SDK 或 base；未来转发前验签、业务权限和高敏感操作复查仍需按接入系统验证。
