# OIDC/SSO 身份接入

用户已确认管理员和审批人接现有 OIDC/SSO，不自建密码账号。基础密钥首期仅使用开发测试软件模式，生产前接 KMS/HSM。

## 当前交付

实现 OIDC 授权码登录回调中的 ID Token 验证适配器，使用维护中的 `coreos/go-oidc` 库验证签名、签发者、受众和有效期，并增加严格校验：

- 仅接受 RS256、PS256、ES256，不允许 none 或共享密钥签名算法。
- 配置的签发者与 JWKS 地址必须使用 HTTPS，默认同主机，不允许请求方指定地址；不跟随重定向。
- 网络请求限制超时与响应体大小，TLS 至少 1.3。
- 绑定服务端生成的 32 字节 nonce，要求规范 base64url 编码并验证与 Token 一致。
- Token 生命周期至多五分钟，拒绝未来签发、过期边界、缺失身份和无效时间。
- 必须具有配置中认可的 ACR 和最近至多五分钟的 auth_time；不默认将密码登录视作多因素认证。
- 多受众 Token 必须具备匹配的 azp，存在其他 azp 时拒绝。
- 身份 ID 使用 issuer 与不可变 sub 的组合摘要，不使用 email 或用户自行填写的名称识别审批人，不直接信任 Token 中的角色作为本地管理权限。

ACR 的安全含义因 IdP 而异，必须由实际身份系统接入评审确认，不能仅配置一个名为 MFA 的字符串就宣称达到强认证或抗钓鱼标准。

## 尚未完成

适配器自身不是完整登录服务。开发入口现已连接授权码跳转、PKCE、state、服务端登录事务与 nonce 一次性消费、会话创建/撤销和 CSRF，详见《开发登录运行》。当前人员权限及审批操作再次认证尚未接入，不开放业务管理 API。

ID Token 仅用于绑定登录事务的回调，不作为管理 API Bearer Token。后续管理 API 应使用受控会话或独立设计的 API 凭据，不能把这里的校验器直接接到任意请求头。

用户后续确认暂无现有 SSO，目前使用本机模拟 issuer、JWKS 和测试 clientId 联调，未访问真实身份系统。提供真实配置后还需验证签名密钥轮换、用户撤权和真实多因素流程。

参考：[go-oidc 官方接口文档](https://pkg.go.dev/github.com/coreos/go-oidc/v3/oidc)。

本机 TLS 测试补充验证了 JWKS 实际远程抓取、签名密钥轮换、禁止重定向、响应体限额、超时、旧 TLS 版本及不可信证书拒绝。测试使用独立临时证书信任，不关闭生产证书校验；没有访问现有 SSO。JWKS 公钥缓存不意味着撤销会立即生效，真实接入需评审缓存、短 Token 生命周期及紧急禁用策略。
