## 当前可运行内容

- `go run ./cmd/keygate`：本机进程存活检查，尚不开放业务接口。
- `go run ./cmd/mock-sso`：TLS 1.3 本机模拟身份服务，支持 discovery/JWKS、授权码及 PKCE。当前开发实例监听 127.0.0.1:19443，连接信息位于被忽略的 `data/mock-sso/connection.json`，进程停止后需重新启动。
- `python3 scripts/test-postgres.py`：独立一次性 PostgreSQL 集成测试，结束后清理测试容器。

本机实际进程已经验证可信 CA/TLS、授权码、PKCE、签名身份和授权码重放拒绝；本机系统 Python 的旧 TLS 库不支持 TLS 1.3，实际进程验证改用 Go 客户端，没有降低服务的 TLS 要求。

## 验证与限制

- 已通过全量 race 测试、静态检查、构建和已知漏洞扫描。
- 真实临时 PostgreSQL 验证了跨 Store 对象并发、一票一次、一 nonce 一次、用量限额及审计失败回滚。
- 这些测试不等于真实多数据中心、高可用或企业级安全认证，未完成部分不能以接口或配置占位代替。
- 模拟 SSO 不具备真实身份认证或 MFA，测试身份的名称不自动赋予本地权限。

【其他业务影响待确认】尚未接入现有业务或真实身份平台，相关调用链与回归验证待后续接入阶段确定；当前未修改其他业务或 base 公共基础代码。
