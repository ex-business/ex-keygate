## 当前可运行内容

- `go run ./cmd/keygate`：默认主服务仍只提供本机存活检查，不自动开放管理接口。
- `go run ./cmd/mock-sso -redirect https://localhost:18761/auth/callback`：模拟 SSO 当前在 127.0.0.1:19443 运行，使用测试身份及模拟认证等级。
- `KEYGATE_ENV=development KEYGATE_ROOT_MODE=development_software go run ./cmd/keygate-dev`：开发登录控制台当前在 https://localhost:18761 运行。
- `go run ./cmd/keygate-dev-smoke`：对实际运行进程验证可信 TLS、PKCE、签名身份、持久会话、错误 CSRF 拒绝、退出及旧会话拒绝，已通过。
- `python3 scripts/test-postgres.py`：一次性 PostgreSQL 全量 race 集成测试，结束后清理测试容器。
- 独立常驻开发数据库已由 `scripts/start-dev-db.py` 创建，仅绑定本机随机端口，凭据在忽略的私有文件中。按《开发登录运行》停止和清理，不操作其他业务容器。

登录与退出已在开发模式形成闭环；尚不是完整密钥认证服务。浏览器 Cookie 使用 Host 前缀、Secure、HttpOnly，退出检查同源与 CSRF；会话不自动获得本地业务权限。

## 验证与限制

- 已通过全量 race 测试、静态检查、构建和已知漏洞扫描。日志并发测试在独立审查发现时序假设后修正，连续 30 次 race 运行及完整数据库复测均通过。
- 真实临时 PostgreSQL 验证了跨 Store 对象并发、一票一次、一 nonce 一次、一次性登录事务、短会话、配置隔离、用量限额及审计失败回滚。
- 数据库脚本所有权及失败清理使用隔离文件和模拟 Docker CLI 验证，未通过测试操作现有业务容器。
- 这些测试不等于真实多数据中心、高可用或企业级安全认证，未完成部分不能以接口或配置占位代替。
- 模拟 SSO 不具备真实身份认证或 MFA，测试身份的名称不自动赋予本地权限。

【其他业务影响待确认】尚未接入现有业务或真实身份平台，相关调用链与回归验证待后续接入阶段确定；当前未修改其他业务或 base 公共基础代码。
