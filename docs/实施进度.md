## 当前可运行内容

- `go run ./cmd/keygate`：默认主服务仍只提供本机存活检查，不自动开放管理接口。
- `go run ./cmd/mock-sso -redirect https://localhost:18761/auth/callback`：模拟 SSO 当前在 127.0.0.1:19443 运行，使用测试身份及模拟认证等级。
- `KEYGATE_ENV=development KEYGATE_ROOT_MODE=development_software go run ./cmd/keygate-dev -enable-key-flow`：开发流程控制台当前在 https://localhost:18761 运行，管理页面为 `/manage`。省略开关时保持仅登录模式。
- `go run ./cmd/keygate-dev-smoke`：对实际运行进程验证可信 TLS、PKCE、签名身份、持久会话、错误 CSRF 拒绝、退出及旧会话拒绝，已通过。
- `python3 scripts/test-postgres.py`：一次性 PostgreSQL 全量 race 集成测试，结束后清理测试容器。
- `python3 scripts/signature-vector.py`：用 Python 标准库独立复核 Go 签名固定向量。
- `go run ./cmd/keygate-client -action init|claim|probe`：接收方本机生成私钥、加密领取、持有证明和签名探测，参数见 HTTP 流程文档。
- 独立常驻开发数据库已由 `scripts/start-dev-db.py` 创建，仅绑定本机随机端口，凭据在忽略的私有文件中。按《开发登录运行》停止和清理，不操作其他业务容器。

已在本任务专用开发数据库显式应用迁移并重启控制台，以三个独立模拟 SSO 会话和真实接收方 CLI 验证客户端创建、签发、领取、持有证明、审批启用、认证和审批停用。实测启用前 401、启用后 200、停用后 401；登录、CSRF、退出烟测通过。浏览器会话不自动授予权限，只有显式模拟流程初始化的本地授权生效。默认演示服务重启创建隔离域和临时根；显式 resume 支持外部签名校验及隔离后的原管理域恢复，不恢复旧软件根。生产灾备仍未验收。

- 已通过全量 race 测试、静态检查、构建和已知漏洞扫描。日志并发测试在独立审查发现时序假设后修正，连续 30 次 race 运行及完整数据库复测均通过。

## 生命周期验证补充

六个实现小点均完成独立审查；全量临时 PostgreSQL race、vet、JS 语法通过。覆盖轮换并行路径约束、泄露终态、恢复有效期与审计故障回滚、新旧凭据认证、旧票/会话失效、预算/nonce/撤销摘要偏差、范围与下载撤权、物化导出、归档故障/重复/篡改/删档和 HTTP 新根审批。

曾有一次全量测试输出被截断，无法确定失败原因；之后修正分钟聚合测试跨分钟的固定单桶假设，并补齐隔离运维与迁移的锁顺序，后续全量测试通过。该说明不将无法确认的原因归结为已证明的修复。

实际 KMS/HSM 按用户要求延后，保留 RootCustodian、权威操作结果查询和 fencing 契约；当时远程 Provider 不可装配；后续只读 HTTPS/mTLS 适配器见下节。未自动创建外部告警或定时任务。

本机实际进程已验证：三组独立模拟 SSO 会话与编译后接收方 CLI 跑通轮换重叠、版本撤销、根撤销、新根审批、隔离签发/证明、再次审批恢复及新旧认证结果；审计越权拒绝，41 条作用域快照及其 SHA-256 一致。独立工具归档 54 个事件，签名清单及数据库比对通过。

另已实际执行状态 capture/verify/quarantine、签名校验后的原域 resume、新登录及再次换钥恢复；并将真实 pg_dump 还原到新建的隔离 PostgreSQL 16 容器，验证原摘要匹配、隔离成功、旧校验点失效及新校验点通过，结束后删除该测试容器。该结果属于单机开发恢复演练，不代替多中心、生产根和真实不可变存储验证。
