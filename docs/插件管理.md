<a id="scope"></a>
## 交付范围

| 类型 | 当前行为 | 接入边界 |
| --- | --- | --- |
| internal-software | 已用于签发、交付、启用及 HMAC 认证；停用立即阻止签发、领取、证明和认证 | 仅开发软件根 |
| third_party | 通用 HTTPS/mTLS Verifier、健康检查、模拟服务、公开向量自检 | 没有装配到真实客户端认证或远程密钥副作用操作 |
| hardware-reserved | DeviceInspector、ChallengeIssuer、ChallengeVerifier 类型及明确拒绝的 ReservedHardware | 无设备访问、挑战产生或真实证明验证，不能启用 |
| KMS/HSM | RootCustodian、结果查询和 fencing 契约保留 | 按要求后续接入 |

启用插件只授权已安装的候选摘要；不会自动增加客户端 Profile 或实现该厂商的认证协议。模拟服务只验证公开测试向量，不用于真实身份认证。

<a id="startup"></a>
## 启动与配置

已有开发数据库及模拟 SSO 的启动步骤见[开发登录运行](开发登录运行.md)。另启一个终端：

```sh
KEYGATE_ENV=development go run ./cmd/mock-plugin
```

默认只监听本机 TLS 19444，生成临时 CA、双向证书和私有 `data/mock-plugin/connection.json`。文件由进程自动生成，不提交 Git、不粘贴私钥到页面。进程持有输出目录锁；异常退出遗留锁需要先确认原进程停止，再人工清理 `.instance.lock`。重启模拟服务会更换证书和公开向量，需要重启控制台重新装配、审批新摘要。

停止旧控制台后启动：

```sh
KEYGATE_ENV=development KEYGATE_ROOT_MODE=development_software go run ./cmd/keygate-dev -enable-key-flow -plugin-file data/mock-plugin/connection.json
```

仅启动方可读取端点、固定 IP 白名单、CA、客户端证书及私钥。配置文件及证书须为私有普通文件。适配器校验 TLS 1.3、证书主机名并只连接白名单 IP；拒绝代理、重定向、未知字段、歧义 JSON 和超限响应，调用超时三秒。配置装配只允许在 Handler 构造前执行。

迁移 9 新增插件表，将现有域内部实现登记为启用，取消未执行的旧密钥／根操作申请，要求重新申请并绑定插件修订。升级前停止所有旧实例，禁止混合运行不检查插件策略的旧版本。迁移不自动授予已有域 PolicyAdmin；当前模拟新域显式授予 demo-requester 该角色。生产初始化仍未交付。

<a id="management"></a>
## 管理操作

进入 `/manage`。身份使用已有 SSO Cookie；写接口还需固定 Origin、会话 CSRF、近期登录。客户端不能自报操作者或提交远程地址。

| 方法与路径 | 条件与用途 |
| --- | --- |
| GET /api/providers | 全域 Viewer 或 PolicyAdmin；返回策略、安装摘要、候选及当前修订的最近检查，不返回地址或凭据 |
| POST /api/requests | 全域 Requester 且 PolicyAdmin 提交启用／配置切换申请；复用已有审批队列 |
| POST /api/providers/{provider}/check | 全域 PolicyAdmin；仅检查已启用且摘要与本进程装配一致的实现 |
| POST /api/providers/{provider}/disable | 全域 EmergencyOperator；立即停用并推进修订，审计失败整体回滚 |

启用请求示例（摘要与修订从列表读取）：

```json
{
  "kind": "provider_enable",
  "clientId": "provider-management",
  "expectedRevision": "1",
  "providerId": "third-party-demo",
  "providerDigest": "<installedDigest>"
}
```

`expectedRevision` 为十进制字符串，不能用旧列表值覆盖新策略。审批清单冻结候选公开配置摘要及管理员授权快照；两名独立审批人批准后由原申请人执行。硬件 reserved 候选在申请阶段拒绝。

```text
Trusted startup -> Register candidate (disabled)
                          |
Requester + PolicyAdmin -> Request -> Approver 1 + Approver 2
                                             |
                                 Applicant executes approved digest
                                             |
                           Enabled -> Health / public-vector selftest
                                             |
EmergencyOperator ----------------------> Disabled (revision + 1)
```

<a id="states"></a>
## 状态与恢复

- `policy.Enabled` 表示数据库授权；`installedDigest` 表示本进程装配。二者摘要不一致时自检拒绝，不能凭“启用”认定可运行。
- `executor=reserved` 表示仅有接口，页面不提供启用按钮。未运行检查不表示 ready。
- 检查状态 ready、unavailable、rejected 分别表示成功、不可用、证明拒绝；`Conformance=true` 仅表示公开向量验证通过。内部健康成功时该值为 false，因为没有执行远程公开向量。
- 检查不持数据库事务跨网络；完成后重新核验会话、管理员授权和插件修订，停用期间晚到的结果不会写回。列表只展示当前修订匹配的检查；网络错误不自动启用、降级或重试。
- 内部插件停用会拒绝旧密钥认证和交付，重新启用不会恢复旧审批票；新操作须重建申请。停用前已提交成功的操作不会被追溯撤回。
- 恢复隔离会停用全部插件、推进修订并撤销旧票／会话。新登录后，先独立审批启用内部插件，再审批新根及隔离换钥恢复。不会加载旧软件根。
- `QuarantineRestored` 为停服维护入口；表锁采用 EXCLUSIVE NOWAIT，任何活动写事务或行锁均立即拒绝并回滚，须停服后重新核对最新签名校验点再操作。

<a id="verification"></a>
## 验证和边界

`python3 scripts/test-postgres.py` 为每个 Go 包重建本脚本临时容器内的 keygate_test，保留包内跨 Store 并发和 race 检查，避免全库恢复和故障注入 DDL 影响其他包。覆盖 mTLS 自检、未批准／越权／CSRF 拒绝、停用后的拒绝、硬件候选不可启用、旧票修订失效和晚到结果拒绝。

真实厂商、真实自然人 MFA、硬件证明信任、KMS/HSM、远程副作用幂等及 UNKNOWN 核对、多节点滚动升级和多数据中心验收均未完成。本机真实进程另以三组独立 SSO 会话和编译后的接收方 CLI 验证：第三方审批后 mTLS 公开向量成功、越权与停用后拒绝、内部插件停用后真实认证 401、重新审批后认证 200，以及轮换、根撤销和隔离换钥回归。

本批未修改其他业务或 base 公共基础代码。
