# 运营管理后台

入口：`https://localhost:18761/login`，完成账号密码或 SSO 及本人二次验证后进入 `/manage`。详见[账号密码登录](账号密码登录.md)。本地启动和证书配置见[本地信任证书](本地信任证书.md)。当前运行模式为开发测试；模拟身份、软件根和模拟插件不代表生产安全验收。

## 页面与职责

视觉参考同系列 `ex-ops-identity-web`、`ex-service-router-web`：灰白背景、白色侧栏、蓝色操作按钮、细边框和紧凑表格。

| 页面 | 可执行内容 |
| --- | --- |
| 工作台 | 当前有权查看的真实数量、本人待办、最近申请、审批策略与本人验证状态 |
| 审批中心 | 按本人待办、本人申请、待本人执行和可见申请筛选，查看冻结变更与逐人流转进度 |
| 客户端管理 | 搜索、类型及状态筛选、登记申请、查看详情及申请启停 |
| 密钥管理 | 共享密钥签发、领取、启用、轮换、停用与恢复 |
| 信任链管理 | 按独立根展开业务服务与证书，导入公开提案、审批发布、轮换、停用与泄露撤销 |
| 验证与绑定 | 查看本人验证方式与插件可用性，完成本人验证，查看受控离线绑定说明 |
| 审批策略 | 查看当前门槛及人员顺序，下载尚未应用的离线变更计划 |
| 人员与权限 | 授权人员查看角色和范围；没有全域审计或策略管理权限时不可读取 |
| 插件管理 | 查看内部、第三方及预留能力，通过审批申请启用配置，执行已启用插件检查 |
| 审计日志 | 按条件查询真实事件，创建本人可见的导出快照并下载 |

无权限、未验证、空记录、连接失败分别显示。数量来自当前授权范围内返回的数据；列表注明查询上限，不作为全域统计。

信任链独立入口为 `/manage#trust`；`/manage#keys` 仅管理共享密钥。两类资源的申请都进入 `/manage#approvals`，不会因页面拆分改变审批或执行规则。

## 审批流程

```text
申请人填写表单 -> 冻结操作内容 -> 当前审批人查看详情
                                   |
                    本人完成申请专用验证组合
                                   |
                    本人明确批准 / 拒绝 / 放弃
                                   |
                  转交下一人 -> 满足 M 名不同人员同意
                                   |
                     原申请人核对并明确执行
```

管理验证与申请验证用途分离。验证完成只返回确认界面，不自动投票；满足门槛也不自动执行。放弃不计为同意票。拒绝及剩余人员不足时沿用服务端终态规则。

表单通过固定幂等键重试同一份提交，修改内容后生成新键；网络失败后应先刷新核对申请状态。密钥接收文件仅接收公开交付配置，不接收私钥。撤销对话框显示版本或基础根的实际影响范围，并要求再次确认。

## 权限与数据边界

独立「信任链管理」页面需启动时配置独立应用根及状态证书，按独立根分组展示应用环境、固定根指纹、业务服务当前版本、修订与停用状态。每个根使用自己的状态签名密钥，服务不能借普通轮换换根。导入仅接收公开证书提案，先预览对象和指纹，再提交多人审批；执行发布会直接启用新版本、退休旧版本。普通停用需要审批，应急泄露撤销需要应急角色并独立确认。已签发的状态证明最多有效 30 秒。生成私钥、离线签发及客户端验证见[应用信任链](应用信任链.md)。

`GET /api/console/identity` 在本人管理验证前只返回本人的身份、角色范围、验证策略及脱敏绑定信息。`GET /api/console/settings` 要求管理验证、全域查看权限，以及全域策略管理或审计角色。

受保护业务接口继续执行原有服务端鉴权；隐藏按钮不构成权限控制。页面使用文本节点渲染服务端内容，CSP 只允许本站脚本、样式和连接。退出、401 及身份失效清理受保护区域；异步查询检查身份代次，客户端恢复查询同时检查客户端，关闭抽屉或验证窗口使旧响应失效。

人员授权、验证方式绑定、策略应用当前仍采用受控离线配置。策略页面下载的是提案，不会直接生效。邮件、短信及硬件能力只有接入可信插件后才可用；KMS/HSM 保留接口，未实现的插件不能计入成功验证或启用执行器。

## 验证与限制

验证包含 Go 权限与脱敏测试、PostgreSQL 事务和并发验收，以及正常证书校验下真实 Chromium 的三身份逐人审批、显式执行和桌面/窄屏布局检查。生产接入、真实硬件注册与多中心设施验收须单独完成。
