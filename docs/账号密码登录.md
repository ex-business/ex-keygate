# 账号密码与二次验证登录

## 入口与流程

管理平台入口为 `/login`。未登录或尚未完成管理二次验证时，访问 `/manage` 会返回登录页。页面保留企业 SSO 登录入口；当前本机模拟 SSO 会明确标注开发用途。

```text
账号 + 密码 -> 待验证会话 -> 本人配置的二次验证组合 -> 工作台
企业 SSO  -> 待验证会话 -> 本人配置的二次验证组合 -> 工作台
```

邮件、短信、TOTP、硬件验证沿用已有原生 MFA 策略及插件。每种方式的 M-of-N 组合由服务端核验，未接入插件不能通过。登录本人验证与审批的逐人确认分别执行；登录成功不会自动批准申请。

账号密码失败统一提示，不区分不存在、停用或锁定。验证器丢失与密码不可用时联系管理员进行受控恢复；当前不提供自助重置或公开注册。

## 离线配置

本地账号必须绑定已有、已启用且已配置原生 MFA 的人员，不创建人员或授予角色。启动时通过 `-local-accounts-file` 读取0600私有JSON文件。文件结构为 `accounts` 数组，每项包含 `username`、已有人员的 `subject` 和 `passwordHash`。不接收明文密码。

用户名使用3至128位小写字母、数字及 `._@-`；界面将账号去除首尾空白并转小写。密码保留原始字符，创建时至少12个字符、最多1024字节，不截断后核验。

口令摘要使用32字节随机盐、PBKDF2-HMAC-SHA256、600000次迭代和32字节结果，编码前缀固定。不能通过配置降低或任意增大成本；不存储可还原密码。实现依据：[OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)、[Go crypto/pbkdf2](https://go.dev/pkg/crypto/pbkdf2/)。此选型不代表通过FIPS认证。

`cmd/keygate-password-hash` 从标准输入生成摘要，不接受命令行密码。受控操作时应使用隐藏输入及私有文件，避免终端回显、shell历史、日志或公开输出。

本机开发可生成随机账号：

```sh
python3 scripts/create-dev-local-accounts.py --output-dir data/local-login
KEYGATE_ENV=development KEYGATE_ROOT_MODE=development_software go run ./cmd/keygate-dev \
  -enable-key-flow \
  -mfa-config-file data/dev-mfa-plan.json \
  -local-accounts-file data/local-login/accounts.json \
  -tls-dir data/local-tls
```

先按[原生MFA与人员流转](原生MFA与人员流转.md)准备各人独立验证器。生成器只对应现有开发模拟人员：`admin` 对应申请人，`approver1`、`approver2` 对应两名审批人。密码仅写入0700目录下0600的 `access.txt`，摘要写入 `accounts.json`；种子保留在独立MFA绑定文件中。不得提交或共享这些私有文件。生成器禁止覆盖已有资料；相同启动账号配置可重复导入，变更摘要或人员映射会拒绝，不默默重置密码。

未配置本地账号时，该入口禁用，SSO仍可用。SSO管理员和审批人仍必须具有本地角色授权。当前运行器仍只允许开发/测试软件根模式，不因此宣称生产可用。

## 登录接口与安全状态

| 接口 | 用途及条件 |
| --- | --- |
| `GET /auth/options` | 返回入口可用性及浏览器绑定的登录CSRF token，设置Secure/HttpOnly/SameSite=Strict的预登录Cookie |
| `POST /auth/password` | 同源Origin、登录Cookie及CSRF头匹配后，提交username/password；成功只返回next=mfa并设置新的待验证会话 |
| `GET /auth/session` | 返回本人会话与会话CSRF；密码阶段不能据此访问业务 |
| `/api/mfa/challenges` 及因子接口 | 复用已有本人管理验证与请求专用验证协议 |
| `POST /auth/logout` | 核验Origin及会话CSRF并撤销会话，页面返回登录页 |

登录CSRF与会话CSRF用途分离。密码成功后消耗预登录Cookie并轮换当前浏览器会话；原MFA证明不会迁移到新会话。会话绝对期限沿用5分钟。重新认证入口显示登录表单，不直接继承已有验证。

全域每分钟最多60次密码尝试，各节点共享权威库预算。已存在账号连续5次错误密码锁定15分钟；锁定期内正确密码也不放行。未知账号执行同等成本摘要计算，不能创建无界限的限流行。每节点最多4个并行密码请求；额外请求返回429，权威库或事务异常返回503并拒绝登录。

预算先在短事务中消耗，密码计算在锁外执行，最后重新锁定并核对摘要、账号状态及锁定期。取消、计算失败或提交不明不返还预算。只有同事务持久化了会话及审计才设置会话Cookie。

## 兼容与回归范围

【涉及其他业务】H5身份兑换和持续认证新增对本地密码会话的MFA门禁：密码阶段不能创建H5会话；完成验证后按既有客户端策略兑换，人员/策略修订、证明失效及账号停用后拒绝继续认证。已有OIDC会话保留原H5规则。登录前只开放必要本人信息、MFA和退出，所有管理接口仍独立鉴权。

新增迁移14，认证来源持久保存为 `sessions.local_password`。身份配置摘要版本同步更新，升级后已有 OIDC/管理会话、依赖身份会话的 H5 会话及进行中的 OIDC 登录事务均失效，需要重新登录；旧版本节点无法认领新版本密码会话。启用本地账号前须先完成全部节点升级，不能以旧节点提供新登录入口。账号和共享预算纳入安全校验点；升级后须重新生成可信校验点，旧校验点不得作为新结构的恢复依据。回滚程序不得删除账号表、会话来源标记或降低摘要成本；停用本地登录可移除启动参数并撤销已有本地会话。

验证覆盖摘要边界、跨节点失败锁定、登录CSRF、未验证管理请求拒绝、H5密码阶段拒绝及证明失效、真实浏览器三身份登录和审批执行、SSO入口及桌面/窄屏布局。真实邮件/短信投递、硬件插件和生产SSO仍需单独接入验收。
