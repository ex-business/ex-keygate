## 服务端接入

使用 HMAC 共享密钥认证，当前开发版已跑通。私钥由业务服务端保管，管理平台只接收公钥配置；共享密钥经审批后加密交付。

![服务端接入方案与流程](images/server-integration.png)

操作说明：[客户端密钥 HTTP 流程](客户端密钥HTTP流程.md)。

## 桌面与移动客户端接入

采用授权码 + PKCE 的设计方案。当前支持客户端类型登记，原生认证执行器和 SDK 尚未交付；图中登录、凭据存储和退出流程为后续实施方案。

![桌面与移动客户端接入方案与流程](images/native-client-integration.png)

模型说明：[人员权限与客户端模型](人员权限与客户端模型.md)。

## H5 接入

使用同源 SDK 和 Cookie 会话，当前开发版已实现。前端不保存私钥或共享密钥，认证成功不代替业务权限判断。

![H5 接入方案与流程](images/h5-integration.png)
