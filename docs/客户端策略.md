# 客户端独立策略

当前实现为策略配置校验，不是认证执行器，不能据此开放认证接口。

| 客户端 | 可配置方式 | 密钥要求 |
| --- | --- | --- |
| 后端 | HMAC、mTLS、硬件证明 | 服务端密钥托管或硬件保护 |
| 桌面 | HMAC、mTLS、硬件证明、联合身份会话 | 本机密钥使用系统密钥库或硬件；联合会话不保存长期共享密钥 |
| 移动端 | HMAC、mTLS、硬件证明、联合身份会话 | 本机密钥使用系统密钥库或硬件；联合会话不保存长期共享密钥 |
| 浏览器 | 硬件证明、联合身份会话 | 不配置长期共享密钥；硬件能力尚未实现 |

各客户端绑定独立、受控版本的 Profile；认证请求不能自报客户端类型或选择其他 Profile 绕过要求。Provider 标识只接受受控 ID，不接受调用方传入的远程地址。

此表是允许配置的候选方案，不表示这些认证方式已实现。联合身份会话需验证签发者、受众、有效期和用途；用户认证与应用身份不是同一概念。硬件证明需定义实际设备协议和信任根；不能仅凭客户端声明拥有硬件就通过认证。

OSKeystore 仅表达策略要求，不保证在客户端完全失陷后密钥仍安全；后续接入必须验证实际密钥保护和证明机制。`none` 表示不保存长期认证共享密钥，不表示没有会话凭据，也不表示允许匿名认证。

默认拒绝未知类型、未知认证方式、零版本以及不符合要求的组合。当前没有认证默认方式或隐式降级。
