# 本机开发登录环境

本环境只用于开发验证：使用本机独立 PostgreSQL、临时软件根、模拟 SSO 和临时测试 CA。没有真实 MFA，不授予管理或审批权限，禁止生产使用。

## 启动顺序

在 `ex-keygate` 目录运行。若对应端口已有本任务实例，可直接复用；需要修改回调时先正常停止旧模拟 SSO，不要启动重复实例或停止其他任务的进程。

1. 创建一次独立开发数据库：

   ```sh
   python3 scripts/start-dev-db.py
   ```

   已有配置时不会覆盖；可直接复用已有数据库。随机密码只写入私有 `data/dev-console/database-url`，不打印、不提交。

2. 在独立终端启动模拟 SSO，回调使用 localhost：

   ```sh
   go run ./cmd/mock-sso -redirect https://localhost:18761/auth/callback
   ```

3. 在另一个终端启动开发控制台：

   ```sh
   KEYGATE_ENV=development KEYGATE_ROOT_MODE=development_software \
     go run ./cmd/keygate-dev
   ```

控制台地址：`https://localhost:18761`。模拟 SSO 地址：`https://127.0.0.1:19443`。两个主机名隔离 Cookie，不把端口当作隔离边界。

## 验证

```sh
go run ./cmd/keygate-dev-smoke
```

烟测使用独立 CA 信任池校验证书，不关闭 TLS 验证，实际验证初始化登录、授权码与 PKCE、身份和会话、错误 CSRF 拒绝、退出及旧会话拒绝。不打印 Token、Cookie、state 或数据库密码。

这属于 HTTP 协议烟测，不是实际浏览器 SameSite 验收。浏览器访问自签名证书时需要适当的单站测试信任；不要将开发 CA 安装成系统全局信任。CA 文件分别在 `data/mock-sso/ca.pem` 与 `data/dev-console/ca.pem`，连接信息分别在对应的 `connection.json`。

登录成功返回确认页，点击“查看当前会话”可查看身份与过期时间。身份验证不代表业务授权，当前不提供密钥管理或审批操作页面。

## 状态与重启

- 软件根和 TLS 私钥仅在进程内生成，退出后丢失。
- 控制台重启会创建新根版本和新配置摘要，旧登录事务与旧会话不能沿用。
- SSO 重启更换签名密钥及 CA；需重启控制台加载新 CA。
- 数据库仅允许私有文件中指向 loopback 的 `keygate_dev`，拒绝远程地址、其他数据库和覆盖连接主机的附加参数。
- 数据库启动脚本仅新建本任务带标签的容器；开发命令在该独立数据库内初始化 schema，不代表生产运行角色可以做 DDL。
- 运行目录和凭据均在 Git 忽略的 `data/`，代码及提交中不含真实凭据。

## 停止与清理

先在控制台和 SSO 终端正常退出，再运行：

```sh
python3 scripts/stop-dev-db.py
```

脚本校验本目录记录的容器名和专属标签后，仅删除该开发数据库容器及其连接文件。数据库为一次性环境，删除后开发数据随之消失，不适用于真实环境备份或恢复。

## 当前限制

生产 KMS/HSM、当前人员权限、管理页面、审批执行器、真实 IdP、真实浏览器和跨数据中心验收仍未完成。本环境不能作为企业级安全认证或生产准入证明。
