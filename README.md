# ExKeyGate

支持插件扩展、共享密钥管理和多人授权的认证服务，采用 Go 单工程。

当前主服务仅提供本机进程存活检查；已实现审批、共享安全状态、密钥保护和 OIDC 验证等基础组件，以及独立模拟 SSO。尚未开放业务认证和管理页面，不提供生产安全保证。详见 [实施进度](docs/实施进度.md)。

工具链：Go 1.26.9（由 go.mod 固定，启用自动工具链时首次运行可能下载）。

运行：`go run ./cmd/keygate`。进程存活检查：`GET http://127.0.0.1:18760/health/live`。该接口不表示业务就绪，不得作为认证能力验收依据。

实施顺序与门禁见 [实施计划](docs/实施计划.md)，功能要求见 [功能设计](docs/功能设计.md)。

正式 module 路径待仓库地址确定后设置。禁止提交真实密钥或环境凭据。

数据库集成测试：`python3 scripts/test-postgres.py`，需要 Docker；使用独立临时容器并在结束后清理。普通 `go test ./...` 未配置专用测试数据库时会跳过数据库集成用例。

本机模拟 SSO：`go run ./cmd/mock-sso`，仅开发测试使用，见 [模拟 SSO](docs/模拟SSO.md)。当前没有可登录的管理页面；测试身份不代表真实多因素认证。
